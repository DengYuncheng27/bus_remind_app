打开下班王

iPhone · 添加到主屏幕

  1. 使用 Safari 打开本网站。
  2. 点击“分享”，选择“添加到主屏幕”。
  3. 从主屏幕打开下班王，登录后进入“我的”。
  4. 点击“开启本机通知”，允许通知并发送测试。
需要 iOS 16.4 或更新版本。创建提醒时，请选择网页通知作为接收渠道。

Android · 手机客户端

安装客户端后，可查询公交、设置提醒，并使用钉钉等高级扩展。

下载 Android 安装包最新稳定版 · ARM64 · 由 GitHub 提供下载。查看版本与更新说明。下载连接不畅时，可先使用网页版。原生手机推送暂未开通；当前可使用社交渠道，或在支持的浏览器中安装网页版并开启网页通知。

高级扩展

在“我的 → 高级扩展”添加钉钉、企业微信、飞书、Telegram 或 Webhook。保存后发送测试，再在提醒的“接收渠道”中关联。
