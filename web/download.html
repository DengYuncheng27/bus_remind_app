还有一点，你可能想知道

出发前的小问题。

Android 版之后怎么更新？+

回到本页下载最新版 APK，或前往 GitHub Releases 查看更新说明。原包名与签名的正式版可以覆盖安装。目前没有应用内自动更新提示。

需要一直开着网页才能收到提醒吗？+

提醒由服务器按规则检查。网页通知正确订阅后，可在页面关闭时交给系统通知服务投递；实际收达仍受浏览器、系统权限与网络影响。请先发送测试通知。

支持哪些城市和线路？+

以应用内当前开放的城市与可查询线路为准。实时信息来自上游数据源，可能存在延迟或缺失，请结合站牌和实际车况判断。

换个设备，提醒还在吗？+

使用同一个账号登录，服务器保存的提醒和渠道会保留。新设备的网页通知需要单独授权和连接。
